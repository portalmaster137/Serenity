# What do?

Hi there, if you are not a member of the Serenity Amalgam,
feel free to do as you wish with these configs.

--- 

Otherwise if you& are a member of the Serenity Amalgam,
then please follow this guide to enroll an account.

To get started, add a user by typing
`micro home/users/users.nix`, copy the template in the
'users.users' block and adjust it to match, then repeat
with the 'home-manager' block below that, then finally
add a $-username.nix file in home/users by copying the
existing template and adding whatever you& wish.
 
A suite of programs and applications has been provided
via a shared home.nix file, as well as a common config
across machines and users.
If you& would like to see what is included by default,
then Serenity's account is considered common/shared by
all members of the amalgam.

Please do not add or remove entries outside of these
mentioned locations,
thankyou& <3
